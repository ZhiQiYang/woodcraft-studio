# 木工設計與裁切估算器

用 3D 組裝構件、編輯設計圖紙，並估算採購與裁切用量。

## 開啟與存檔

直接以瀏覽器開啟 `index.html`。網頁會在目前瀏覽器儲存進度。要備份或換裝置，請從「檔案」下載 JSON，再到另一個瀏覽器開啟專案檔。

裁切估算會分開列出超過庫存規格的構件。採購數量和小計只包含可裁切的材料，請先處理超尺寸項目再採購。

## 開發與測試

應用的 HTML、CSS 與 JavaScript 都在 `index.html`。修改後執行 `node --test`，再在手機尺寸確認可切換「3D 組裝」、「設計圖紙」和「圖紙＋3D」。

## 部署

把 `index.html` 作為靜態網站的首頁即可發布。Cloudflare Git 建置可用以下指令準備資產，將 `dist` 設為靜態資產目錄。

```sh
mkdir -p dist && cp index.html dist/index.html
```

部署後，把正式 HTTPS 網址填入 LINE 官方帳號「圖文選單」的第三格。確認能從手機 LINE 開啟網站、編輯圖面及匯出專案。
