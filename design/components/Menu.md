# Menu

從按鈕展開的選單,裝不常用但一定要找得到的操作。兩個工具都有一個「檔案」選單,內容與順序一致。

結構:`gb-menu`(`role="menu"`)裡放 `gb-menu__item`(`role="menuitem"`,圖示加文字,可選的 `gb-menu__meta`)、`gb-menu__label`(分組小標)、`gb-menu__sep`(分隔線)。危險項目加 `gb-menu__item--danger` 並放在最後、用分隔線隔開。

檔案選單的固定順序:

1. 專案:匯出專案、匯入專案、(木工)載入範本
2. 輸出:(木工)複製採購清單、列印施工單;(房間)匯出平面圖、匯出剖面圖
3. 清空畫布

用詞固定為「匯出專案」「匯入專案」,不寫「下載 JSON」「開啟離線專案檔」;副檔名放在 `gb-menu__meta`。

你要提供:項目、圖示、點了之後要做的事。每個項目高 44px,整列都是點擊範圍。開啟時焦點移到第一項,上下鍵移動,Esc 關閉並把焦點還給觸發的按鈕。

手機上同一份內容放進 Sheet,不用這個浮動選單。
