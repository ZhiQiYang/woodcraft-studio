# DimChip

畫布上的尺寸標籤:捲尺黃的底、墨色的數字。這套系統最有辨識度的元件,3D 構件旁、平面圖的尺寸線上都用它。

黃底配深色字在木料、混凝土、白色圖紙上都讀得到,而且和「選取」的藍色不會混淆。

- **一般** `gb-dim`:黃底墨字,1px 深黃邊(讓它在白紙上也有邊界)。
- **編輯中** `gb-dim gb-dim--active`:反過來,墨底黃字。使用者點了某個尺寸、正在輸入時用。
- **參考** `gb-dim gb-dim--ref`:白底墨字。不能直接編輯的讀數(房高、剖切高度)。
- **名稱標籤** `gb-tag`:藍底白字,標示選中構件的名稱,和藍色外框是一組。

你要提供:數字,以及必要時的單位。同一張圖的單位都一樣時(房間的平面圖全是 mm),標籤只寫數字,單位寫在畫布角落;木工的 3D 視圖每個標籤都帶 `cm`。千位加逗號:`6,000`。

可以點的標籤用 `<button>`,並給 `aria-label`(「編輯尺寸 4,500 mm」)。

在 SVG 或 canvas 裡自己畫的時候,用同一組值:底 `--gb-measure`、字 `--gb-on-measure`、邊 `--gb-measure-edge`、圓角 3px、字 13px / 600 Barlow Semi Condensed。尺寸線本身用 1px 的 `--gb-ink-2`,不要畫成黃色。
