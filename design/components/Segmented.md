# Segmented

二到四個互斥選項的切換,用來表示「我現在在哪一個檢視」:木工的 3D 組裝/設計圖紙/圖紙+3D,房間的平面/3D/雙視圖/剖面,以及清單上方的篩選。

目前所在的那一格用墨色填滿、白字。它回答的是「我在哪」,所以用墨色;藍色留給「我選了什麼」。

你要提供:每一格的文字(二到四個字),可選的圖示,以及 `role="group"` 加 `aria-label`。目前那一格設 `aria-pressed="true"`。

`gb-seg--block` 會撐滿容器、每格等寬,用在側欄和底部抽屜裡。

超過四個選項、或手機寬度放不下時,改用 Select。不要拿它當一排各自獨立的開關,那是 Button 加 `aria-pressed`。
